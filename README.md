# Kuzmínovo Trails

Navrhni modernú, vizuálne atraktívnu a responzívnu webovú stránku pre kopec Kuzmínovo so zameraním na turistiku a športové aktivity.

🎯 Cieľ stránky:

Stránka má propagovať outdoorové aktivity ako:

beh do kopca (hill climb running)

cyklotrial / horská cyklistika

turistika a rekreačný pohyb

🎨 Dizajn:

Použi prírodné farby (zelená, hnedá, modrá obloha)

Hero sekcia s veľkou fotkou kopca/lúky a hôr

Dominantný veľký nadpis: „Naše Kuzmínovo“

Podnadpis: „Miesto pre pohyb, prírodu a výzvy“

Moderný minimalistický štýl (inšpirácia: https://kuzminovo.lovable.app a outdoor weby)

🧱 Štruktúra stránky:

Hero sekcia

Veľký názov „Naše Kuzmínovo“

Krátky slogan

CTA tlačidlo: „Zaregistruj sa na preteky“

O mieste

Krátky popis kopca Kuzmínovo

Výhľady, príroda, náročnosť terénu

Aktivity

Beh do kopca

Cyklotrial

Turistika (každé s ikonou + krátkym popisom)

Galéria

Fotky lúky, lesa a hory

Dynamické rozloženie (grid)

Podujatia / Preteky

Ukážka pripravovaných eventov

Dátum, názov, obtiažnosť

Registračný formulár

Vytvor jednoduchý formulár:

Meno a priezvisko

Email

Telefón

Výber aktivity (dropdown)

Súhlas so spracovaním údajov (checkbox)

Tlačidlo: „Registrovať sa“

Footer

Kontakt

Sociálne siete

Lokalita (mapa alebo odkaz)

⚙️ Technické požiadavky:

Responzívny dizajn (mobil, tablet, desktop)

Jednoduchý clean HTML + CSS (alebo moderný framework)

Rýchle načítanie

SEO základ (title, meta description)

🧠 Štýl:

Energetický, motivujúci, športový

Zameraný na komunitu a pohyb v prírode

Výsledok má pôsobiť ako moderná landing page pre športové podujatia na kopci Kuzminovo
